# Complete saved model replies

The reported memory-wall council completed all ten public model requests. Its apparent missing replies had two causes: Compare filled unassigned columns with “No saved reply,” and structured review rendering showed selected fields rather than the complete public reply. The original provider receipts and answer-delivery records remained intact.

## Presentation and recovery

- Claim extraction, scrutiny, recheck and final synthesis appear as shared steps with their actual author's name. Independent answers and individual revisions retain model columns.
- New structured replies render every supplied public field, including notes, limitations, candidate tests and supplemental ideas. Mixed prose, malformed JSON and ambiguous duplicate fields remain intact instead of disappearing.
- **Full model reply** opens an existing reply on demand. Compare's expanded reader also loads the complete saved reply and can switch between readable and original text. Reading and copying never dispatch inference.
- The authenticated original-response endpoint selects only saved public answer text. It verifies the stored delivery hash, or the provider artifact hash for legacy receipts. It never returns the request, credentials or reasoning stream.
- Existing messages, publications, financial records and original receipts remain unchanged. Previously shortened presentations can be inspected in full without rewriting their historical review or requesting another answer.
- Routine conversation polling returns availability metadata only; large original responses load when the user opens them.

## Review resilience

A source-document ID is not a scoped review-evidence ID. An otherwise usable objection with an invalid evidence reference remains an unverified model assessment. The unsupported reference is retained separately and grants no evidence authority. Stale claim/revision references still remain unlinked. This preserves useful criticism and the planned deliberation without inventing verification.

An arithmetic tool result of `unknown`, including unsupported formula syntax or units, is a tool limitation. It does not establish a failed calculation or defeat the model's proposal. Prompts now state this distinction and describe the supported audit-expression format.

These changes impose no new answer-length, reasoning, context, spending, or model-selection controls. No automatic billed retries or extra format-repair calls were added.
