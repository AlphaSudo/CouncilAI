# Keep the discussion when review formatting fails

The reported second cycle of the memory-bandwidth chat used the earlier review profile. Its saved extraction warning was `families.0.mechanism: Field required; families.1.mechanism: Field required; families.2.mechanism: Field required`. The fallback recorded scrutiny, all three author responses and recheck in `skipped_keys`, then published a qualified synthesis. Those stages were actually skipped, not hidden by Compare. The completed messages, receipts, charges and publication have not been rewritten or replayed.

The current answer-first workflow now preserves the planned public discussion when typed annotations cannot be used. New contracts record prompt version `answer-first-council/2`. Healthy formal review still uses source/revision checks and can isolate a malformed family while retaining independently valid claims. If extraction produces no trustworthy claim index, or a whole sidecar fails, the remaining existing turns use actual saved public messages in English Markdown:

1. The critic challenges the independent answers with their actual authors.
2. Each assigned author responds, retains, qualifies or revises their proposal.
3. Recheck compares the actual objections and responses, identifying remaining disagreements.
4. The lead synthesizes those messages without implying that missing formal labels mean agreement or verification.

The fallback does not repeat extraction, redo openings, add a format-repair request, change models, add another round or authorize a larger budget. Existing funding, attempt, provider, Pause/Stop and integrity boundaries still apply. A genuine resource boundary can still prevent a request; that is distinct from optional metadata failure. Review annotations stay incomplete, with `grants_authority: false`; this mode does not create claim/evidence/revision/closure records. Healthy later cycles clear this state. Historical earlier-profile chats adopt the current workflow only on an explicit new request in that chat, preserving earlier publications.

A fully generated final response now retains the normal “Final synthesis” label even when optional review is incomplete. Actual partial generation still gets the partial label. Both the conversation and Compare use this distinction. A quiet note explains when the council continued in prose.

`tests/test_review_continuity.py` first reproduced the premature jump, then tests invalid/ambiguous extraction JSON, no trustworthy claims, a missing family mechanism, all assigned authors, current-turn context, third-cycle recovery and immutable prior messages. Mock HTTP/SSE tests exercise the real provider/controller/settlement path with the original ten-call schedule and no real provider traffic. Surrounding answer-delivery, context, spending, restart, export and browser tests cover the affected boundaries. Human model quality is not inferred from these synthetic tests.
