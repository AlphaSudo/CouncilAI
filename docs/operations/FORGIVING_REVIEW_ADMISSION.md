# Forgiving model output admission

Admission policy `council-admission/4` treats harmless presentation differences as local adjustments instead of paid-request failures. This policy applies to the current council; historical profile limits retain their prior behavior.

The current review accepts readable text and Markdown fences around a complete JSON object, trailing commas outside quoted strings, and repeated identical objects. It admits the repeated object once. Different competing objects, duplicate field names and incomplete structured replies are not guessed away. Original receipts and surrounding commentary remain saved.

Equivalent enum words tolerate case, spaces, underscores and hyphens. A single supplied item can represent a one-element list. Optional null collections and empty-text fields become empty values. Numeric audit inputs can use JSON numbers or decimal text. Unit defaults, numeric tolerances and positive checks are never inferred from null values. Additional model fields are preserved outside authoritative data. Model attempts to provide trusted origins, permissions or verification authority still fail admission.

Missing editorial explanations and limitations are explicitly marked as not supplied. Valid short explanations are accepted. Missing observation rationales retain their more conservative partial, unverified status. Actual assertions, revised assertions, sources, author coverage, finding IDs, current revisions and required review responses remain required.

Descriptive fields accept structured notes as well as paragraphs. Lists render as readable bullets; objects render as labeled notes, preserving nested values, order, zero and explicit null. This applies across extraction, scrutiny, repair, recheck and synthesis, including prose in nullable fields and text-list items. The exact original structure is retained in the admission record. Empty family assumptions/resources are explicitly marked as not supplied. This conversion does not apply to IDs, enums, revision numbers, arithmetic expressions, units or numeric operands, and does not grant verification authority. Empty revised assertions still fail the actual-revision guard.

Two claims per author remains a prompting target. Current councils can retain up to eight claims in total and repair every claim assigned to an author in that author's existing turn. The legacy four-claim and scoped two-claim author limits remain unchanged. The execution schedule, token limits and financial caps are unchanged.

An auxiliary inventory entry with an unresolved source or claim link is saved as an unverified note and excluded from the linked inventory. This marks the inventory incomplete. It does not supply evidence, change a claim source, or stop a valid claim review. Invalid primary claim sources and unrelated audit/observation references still require attention.

Every recorded adjustment includes its path, original value and reason in the admission record. Raw replies are retained. Local restoration is idempotent, requires an unchanged current turn and a complete identified reply, and never sends inference or resumes the council.
