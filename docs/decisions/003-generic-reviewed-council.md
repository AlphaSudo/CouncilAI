# Generic reviewed council and direct providers

October 19, 2026. Implementation decision for version 1.01.

Keep Discussion as the compatible default and add Reviewed council as an opt-in protocol. Reuse SQLite records, artifacts, director authority and the single durable executor. Claim extraction, scrutiny, author repair and recheck are model functions; server publication policy enforces references, provenance and honest scope, not arbitrary semantic truth.

The director replaced OpenRouter with four direct accounts and confirmed all four have free access. Save credentials only in ignored local environment configuration. Each seat has an explicit provider and model ID. There is no alternate-provider or paid fallback. Older OpenRouter conversations remain inspectable; new inference through it is disabled by default.

Support two to four reviewed participants, amending the initial plan's two/three-model limit. Planned calls are `2N + 4`; four models require twelve planned calls and three shared retry attempts. Existing twenty-attempt conversation limits remain. Direct-provider workspace safety limit is one hundred attempts per UTC day; actual provider quotas remain separate and may be unknown. A successful free-account response without reported cost is recorded as cost not reported, not certified zero monetary usage.

Use GLM 4.7 Flash, Gemini 3.5 Flash Lite, NVIDIA Nemotron 3 Super and Groq GPT OSS 120B. An initial NVIDIA Super VL probe reported a different internal model identifier and was rejected. The documented Nemotron 3 Super endpoint returned its expected identity in a separate explicit probe. No runtime fallback made that change. A literal private/ deployment prefix is retained as raw identity and normalized only when the remainder exactly matches the requested model.

Visual thesis: preserve the existing quiet green council workspace, using a plain transcript and one secondary inspector.

Content plan: prompt and mode selection first, visible phase messages second, claim/evidence detail on demand, and a useful final answer with computed labels.

Interaction thesis: use a short inspector entrance, clear disclosure controls, and existing visible phase/retry updates. Keyboard focus stays inside the inspector and motion respects reduced-motion settings. No new landing page or decorative dashboard is required.

The quality harness and human evaluation remain separate. A successful fixture or live workflow demonstrates integration, not a general improvement in answer correctness.

Actual provider testing informed three bounded adaptations. Extraction selects server-numbered original passages instead of asking a model to copy Markdown exactly. Model-facing context exposes logical claim IDs without competing database revision IDs. Repair assertions may use 1,600 characters to preserve qualifications. Review category names are bounded descriptive text; they cannot grant execution or verification authority. Strict status, ownership, reference, revision and server-field rules remain.

Unresolved proposals can appear in a direct conditional recommendation under an application-rendered uncertainty heading. This preserves usefulness without upgrading them to supported results. Recorded contradictions and withdrawals remain excluded from positive recommendations. Supported sections still require the computed supported permission; invalid references still trigger the local final fallback.
