## What is available

- **Usage on each reply and conversation totals:** input, ordinary input, cache reads/writes where reported, visible output and reasoning with provider-specific inclusion rules. Expand a reply's usage for category quantities, unit prices, line amounts and missing information. Explain also shows physical attempts, failures, replacements, research continuations and cumulative coverage.
- **Sources:** attach selected documents before starting, import later, save a public URL, search locally and read exact versioned passages. Text, Markdown, static HTML, PDF text and DOCX paragraphs/tables are supported. Scanned PDFs disclose that OCR is unavailable. The library is scoped to the conversation and shared by its authorized seats.
- **Search the web:** opt in under Customize or change research for the next request in Sources. Tavily Basic Search is the only remote search adapter. A public search query can be supplied explicitly; Council does not automatically upload the original question as a query. Models can request bounded searches/fetches and local library operations.
- **Auditable evidence:** immutable raw/text versions, source snapshots, exact read receipts, clickable source citations, context manifests and portable source/usage export. A citation or successful fetch does not establish truth. Refreshing cited content flags affected current conclusions for source-aware review without rewriting old publications.
- **Context reuse:** local FTS5 lookup, bounded passage reads, stable prompt prefixes, deduplicated retrieval and deterministic source offload. Original messages, mandatory findings, qualifiers and source versions remain available.
- **Recovery:** durable tool checkpoints reuse completed work. Unknown external outcomes retain their reservations and need an explicit human retry; a model cannot authorize that retry. Existing chats continue under a new bounded request window in the same conversation.

Simple and Explain display the same saved work. Opening Sources, changing views, looking at usage, refreshing the page or exporting does not invoke a model or perform web research.

## Bounds and deliberate gates

| Resource | Current policy |
| --- | --- |
| Four-seat review with research | 12 planned contributions + at most 5 research continuations + 3 shared recovery attempts, inside 20 physical model attempts per full window |
| Search | At most 3 Basic queries per window, 5 results/query; local ceiling 900 credits/month across conversations; live free-plan headroom checked before a new query |
| Fetch | At most 6 attempts and 12 MiB reserved per window; 2 MiB compressed/decoded response bounds, 20-second deadline, 3 redirects |
| Local tools | 12 operations / 48 KiB retrieved per contribution; 16 KiB per exact read, with next-range metadata |
| Context | Mandatory fields preserved exactly; selected source budget 16 KiB and full pack bound 100 KiB; oversized required context holds rather than silently dropping obligations |
| I/O concurrency | At most two public fetches; dependent tools ordered; one model call per provider |
| Generation | Exact configured four seats retained; Gemini native tools live verified; Z.ai/NIM/Groq use strict structured actions by default and have native transport contract fixtures |
| Paid capabilities | Explicit billable caches, warmers, LLM summaries and provider-native paid search remain disabled. Parallel model openings remain gated off. OpenRouter remains disabled; Token Factory retains its billing verification gate. No GPU introduced. |

The local counter does not control provider billing or guarantee that free upstream quotas can complete every council. Tavily admission requires the observed free Researcher plan and remaining headroom; it does not certify account payment settings. Other applications using the same key can consume allowance independently.

## Cost interpretation

Amounts use Decimal arithmetic and frozen dated rate cards. Provider-reported charges, applicable-tariff estimates and published-price equivalents are separate. Missing cache/write/reasoning/price/charge data stays unknown. A known subtotal is not an invoice total. The exact configured NVIDIA hosted tariff remains unknown. No price or usage field is manufactured to label a request free.

Each new dispatch freezes a price card and calculator version. Historical stored assessments retain their calculator behavior; enrichment of older calls is explicitly labelled and never dispatches inference. The raw provider usage payload is retained with a hash. Gemini's reported candidates and thoughts are disjoint; Groq's reasoning is a subset of reported completion. Cached input is counted once as a prompt subset.

The genuine Gemini pilot returned prompt/candidate counts but no cached/thought counters or monetary charge. Its two original cost assessments reproduce unchanged; they are not converted into a verified zero invoice.

## Operations

Keep keys in ignored `.env.local`. `TAVILY_API_KEY` enables optional search availability; absent credentials still permit local imports/search/reads and explicitly requested public URL retrieval. No CLI subprocess is used for runtime search. The Tavily CLI/skills remain coding-agent tools.

Install the locked Python dependencies and build `apps/web` as described in the README. Use one localhost server/executor per data directory. Stop the server before `scripts/backup.py`; backups now include source blobs and review exports. Restoring intentionally clears paid-mode verification. Portable source exports can omit content explicitly, in which case offline replay limitations are recorded.

Validation commands that do not repeat the genuine pilots:

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe scripts/evaluate_research_105.py
.venv\Scripts\python.exe scripts/validate_research_release_105.py
npm run build --prefix apps/web
# In apps/web:
npx playwright test
```

The live smoke scripts refuse to silently reuse their existing model pilot and should not be used as ordinary regression tests. The release archive excludes credentials, user chats and private brainstorming files; it is a local reviewable artifact, not a deployment.
