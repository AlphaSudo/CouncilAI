Explicit selected-claim challenges review the affected dependency closure in the same chat. Ambiguous free-form requests use a full cycle. An out-of-scope targeted request re-preflights expansion and retains the counted scoping call. **Explain this answer** generates an explanation of the saved review without upgrading its evidence or claiming a fresh review.

## Scoped checks and their limits

Typed descriptors can request bounded arithmetic, units and quantity kinds, resource/boundary accounting and citation-provenance checks. The application executes only its allowlisted numeric operations. Results retain exact declared inputs, scope, source/revision references, hashes and limitations. A changed assertion invalidates the original descriptor; no successful number is transferred to the new wording automatically.

Arithmetic checks distinguish percentage points, compatible units, decimal/binary memory sizes, angle/index and energy/power within the small declared registry. Unsupported syntax or missing inputs stays unknown. Explicit rounding tolerance is supported. Numerical consistency does not prove a derivation or physical applicability. Resource checks examine declared terms and missing ratio boundaries, not universal completeness. Citation checks distinguish supplied content and human scope assessments from a generated title or reference. No new search account, external retrieval service or GPU is required.

Approach families preserve source ownership, assumptions, resources and distinguishing tests. They must be reassessed after changes. Rankings use current families, preserve their actual review/evidence labels and cannot positively rank withdrawn material. A request for five families may honestly return fewer; it cannot manufacture independence from duplicate variants.

The visible answer remains generated prose. Structural/reference checks and conservative observation warnings cannot establish semantic truth. Invalid finals have a readable local fallback, and the failed raw reply remains saved. No model-written shell code or hidden format-repair inference is executed.
