# Version 1.01: generic reviewed council and direct model seats

Date: October 19, 2026, Africa/Cairo. Package version: 1.1.0. Status: development candidate; Reviewed council is opt-in.

The new protocol preserves independent openings, extracts source-linked claims, records scrutiny, lets each author repair or withdraw its claims, rechecks the responses, and synthesizes with server-computed evidence labels. The final answer retains unresolved issues and a traceable claim ledger. Invalid synthesis falls back to a conservative local summary without another API call.

The director replaced OpenRouter with four direct accounts and confirmed free access. OpenRouter is hidden from new chat/research selectors and blocked by default in dispatch; saved evidence remains readable. The explicit seats are:

The initial Super VL probe reported a different internal model ID and was rejected. Nemotron 3 Super was then selected explicitly and returned its expected identity. This was a configuration change, not runtime fallback. Credentials remain in ignored server-side environment configuration.

## Implemented behavior

- Compatible Discussion and versioned Reviewed council protocols, supporting two to four selected seats. Reviewed schedules plan `2N + 4` calls and three shared retry attempts at start.
- Exact source-unit selection with original character offsets. The model cannot change quoted text by normalizing Markdown. Semantic extraction coverage remains fallible.
- Immutable claim revisions, findings, replies, recheck assessments, human dispositions, evidence links and frozen publication snapshots.
- Strict model DTOs separate from trusted server fields; ownership, revision, reference, integrity and bounded-context checks.
- Conditional, unresolved, scoped human-assessed support, withdrawal and human-assessed contradiction labels. Agreement or confidence cannot grant external verification.
- Supplied source excerpts and scoped existing tool evidence. A URL alone is rejected; relevance requires an explicit human assessment.
- Stale-evidence/final handling, governed contract changes and explicit reassignment within selected available members.
- Durable retry waits, pause/stop, attempt accounting and interrupted-request recovery. Missing mandatory review does not silently count as complete.
- Desktop/mobile claim inspector, keyboard controls, portable export and credential-free label reconstruction.
- Provider-specific adapters, exact identities, raw artifacts, no paid tools/routing fallback, and reported-cost anomaly locks.

## Evidence and limitations

See [current acceptance status](../validation/review-1.01-status.json), [development integration](../validation/reviewed-council-live.json), and [main-app integration](../validation/reviewed-council-main-app.json). Failed attempts remain counted. The [excluded diagnostic run](../validation/reviewed-council-excluded-run.json) is explicitly excluded from acceptance evidence.

Backend checks cover authority, ownership, wrong critics, unsupported novelty, evidence integrity, stale dependencies, scope, revisions, every-phase retry, reassignment, context overflow, final fallback and offline reconstruction. The eighteen [generic protocol cases](../../benchmark/review_cases.json) are developer-authored invariants, not independent human semantic labels. UI checks cover the complete sequence, evidence attachment, stale-final indication, export, mobile fit, keyboard handling, direct-provider preview and the original research workspace.

The [quality protocol](../evaluation/QUALITY_PROTOCOL.md), frozen-manifest template and credential-free scoring summarizer are implemented. Their strict records preserve denominators, incomplete runs, synthetic-versus-reported-human label origin and unknown invoice cost. No human labels or improvement claims are fabricated.

Initial source passages are bounded to 400 characters. Repaired claims may use 1,600 characters to retain qualifications; this adapts the initial plan after actual provider testing. Oversized required context is held, not silently discarded. Malformed non-final model output requires an explicit retry; there is no hidden format-repair inference.

Direct APIs in the probes omitted monetary cost. The director's free-account confirmation records spending authority; it does not independently establish provider invoices. Provider quotas and availability remain outside the application's control.

Token Factory billing authorization and target NVIDIA/Token Factory runtime evidence, independent human quality comparison, public repository/video and external submission acceptance remain separate pending gates. No GPU or domain specialization was added.

## Rollback and evaluation

Select Discussion for new conversations. Existing reviewed conversations keep their protocol and records. An unavailable phase can be retried, explicitly reassigned, or ended with a labelled partial final. Older transcripts are never retrospectively called reviewed.

Keep Reviewed council opt-in until paired generic tasks receive qualified human scoring. Preserve adverse outcomes and report actual calls, latency, failures and uncertainty before claiming improved reasoning. A successful workflow is integration evidence only.
