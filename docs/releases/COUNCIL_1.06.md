# Council 1.06 release record

Public answers are committed before review interpretation. Record-level review failures now retain valid annotations and quarantine invalid neighbors; wholly unusable metadata can finish as incomplete review. Terminal stage results prevent repeated formatting work. New final answers use Markdown and can include conditional, explicitly unreviewed alternatives.

Public streams have durable replay cursors and redact secrets across chunk boundaries. Restart recovery reuses matching completed receipts locally without new inference. Genuine failed/empty/partial provider results keep their actual state and other received responses. A failed lead can produce a clearly attributed local partial result. Explicit Pause/Stop, source permissions, provenance and financial boundaries remain authoritative.

The new baseline uses independent openings, selective scrutiny, grouped author responses, recheck and natural synthesis. Failed falsification is a valid assessment; minor issues need not consume repair turns. Default planning retains the existing `2N+4` successful-call ceiling, with bounded tools/recovery and a new explicit request window for follow-ups. Steering is queued at turn/opening barriers. Historical protocol adoption carries a shared checkpoint without rewriting earlier authors or publications.

Before optional review, finishing credit is planned from the actual saved answer packet, selected lead/prices/output bounds and an annotation-growth allowance. It is refreshed as context grows and may expand at final admission within existing authority. It creates no input limit, no output cut-off, no arbitrary new conversation cap and no request attempt. Shared context stays 262,144 tokens; the aggregate $24 existing-credit cap, unknown holds and $0 additional-payment authority remain enforced.

Simple shows public answers and a quiet relevant incomplete-review note. Explain includes stage results, warning paths, original values, quarantine and the decision brief. Copy/export retain public text; view changes dispatch no inference. Dark surfaces, capped composer height, compact widths, local math and source/usage inspection remain available.

## Limits and deferred claims

The [human quality corpus](../../benchmark/answer_first_106_quality.json) is frozen and unlabelled. Workflow success does not establish scientific correctness, model quality gains or superiority to the earlier council. A malformed sidecar may leave review absent, and genuine provider/context/funding/storage failures remain possible. The advisory thinking target is not a provider-enforced thinking-only cap. No GPU or kernel experiment was performed, and no universal latency guarantee is made.

B08's chronological test-first condition has a documented exception: seven initial failing tests preceded dispatch changes, while the expanded fault register was developed during implementation. The full test-order requirement cannot be claimed retroactively.

[Submission requirements](../validation/answer-first-1.06/submission-requirements.md) were checked against the official event pages. Public repository/demo publication, video production and the submission form remain separate user-owned submission work; no entry was submitted by this task.
