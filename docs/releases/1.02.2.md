# Make the existing 1.02 pipeline the current workflow

Application 1.2.2. This is a forward integration correction, not a rollback and not an implementation of every new auditor suggested in the N4 review.

The physics Discussion run bypassed claim review. Both the UI and API now default to Scoped review 1.02. A visible method label distinguishes it from original 1.01 review and Discussion without a ledger. Historical protocol/policy readers remain available so saved work stays interpretable.

On an eligible older chat, the composer says **Next message: scoped review - 1.02**. Sending that message explicitly requests a full 1.02 cycle in the same chat. **Keep current method** permits an intentional legacy continuation. No model call or historical conversion happens merely by loading the chat.

The transition archives the earlier protocol/hash, review ID and final-answer reference. It preserves all existing messages, source authors and prior publications. It creates a fresh review record with a distinct cycle number and a baseline restricted to that cycle. Earlier Discussion is not retroactively labelled reviewed. Original 1.01 and new 1.02 publications reproduce together in an export pack.

The full review schedule and daily allowance are preflighted before changing the conversation. The transition cannot occur during an active request. Existing billing gates, call accounting, free-model attribution and zero additional-payment/GPU constraints remain in force.
